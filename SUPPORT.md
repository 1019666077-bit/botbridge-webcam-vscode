# Support

Thanks for using **Bot Bridge Webcam**.

## Where to get help

- **Issues / bug reports:** <https://github.com/1019666077-bit/botbridge-webcam-vscode/issues>
- **Homepage / docs:** <https://botbridge.dev/webcam>

When reporting a problem, please include:

- Your VS Code version (**Help → About**).
- The output of **Bot Bridge Webcam: Check Environment** (Command Palette).
- Your OS and whether `uv --version` works in a terminal.

## Scope

This extension is the free, open-source VS Code wrapper around the local
[webcam MCP](https://github.com/1019666077-bit/webcam_mcp). Issues in the MCP
server itself (camera errors, capture quality) belong in the
[webcam_mcp issue tracker](https://github.com/1019666077-bit/webcam_mcp/issues).

The **Pro tier and the desktop Helper** are separate commercial products and are
not supported through this repository.
